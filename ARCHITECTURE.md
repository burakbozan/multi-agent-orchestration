# Architecture Overview

## 🎯 Vision
A modular, reusable framework for orchestrating multiple AI agents in software projects.

## 🧩 Core Components
- **Prompts Library**: Defines roles and constraints for each agent.
- **Workflow Definitions**: JSON/YAML files describing orchestration order.
- **Examples**: Applied workflows for real projects (Task Manager API, Chat App, Note App).

## 📐 Design Principles
- Separation of concerns: each agent has a single responsibility.
- Orchestration-first: workflows define execution order.
- Reusability: prompts and workflows can be applied across projects.
