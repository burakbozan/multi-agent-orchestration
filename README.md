# Multi-Agent Orchestration Framework

This project provides a reusable scaffold for designing and running multi-agent workflows (Planner → Researcher → Coder → Reviewer → Orchestrator).

## 🚀 Features
- Modular agent prompts (stored in `/prompts`)
- Generic orchestration workflow definition (`/workflows`)
- Example applied to Task Manager API (`/examples`)
- Professional architecture documentation (`ARCHITECTURE.md`)

## ▶️ Getting Started
1. Clone this repo.
2. Review agent prompts in `/prompts`.
3. Use `/workflows/generic-orchestration.json` to orchestrate agents.
4. Adapt `/examples/task-manager-api-orchestration.md` for your own projects.
